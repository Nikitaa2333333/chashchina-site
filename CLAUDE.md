# Сайт Оксаны Чащиной — врач-косметолог, превентивная медицина

Персональный сайт-лендинг на Astro. **Дизайн переписывается с нуля.**
Прежняя оливково-розовая система (по мотивам farmminerals) снята целиком
в августе 2026 — вместе с ней удалены `DESIGN.md`, `SPACING.md` и
`variants.css`. Полная история старого дизайна осталась в первом
репозитории `Nikitaa2333333/dr.chashchina`, если что-то понадобится поднять.

## Что осталось и что заново

**Осталось (не ломать):**
- структура главной и все тексты — блоки идут в утверждённом порядке;
- логика анимаций: посимвольный ревил `[data-split]`, IntersectionObserver
  для `.reveal`/`.reveal-group` (скрипты в [Layout.astro](src/layouts/Layout.astro)),
  галерея на RAF с lerp ([Gallery.astro](src/components/Gallery.astro)) —
  **это второй блок страницы, его поведение сохраняем**;
- русский типограф (висячие предлоги → nbsp, ядро в [src/lib/typo.ts](src/lib/typo.ts));
- фото и видео в `public/`;
- инварианты набора в `global.css`: капс запрещён, жирный/курсив внутри
  абзацев запрещены (стоят предохранители), перечисления без буллитов и
  разделительных линий.

**Заводится заново:** палитра, шрифт (Onest снят, пока системный стек),
шкала кеглей, мера строки, вид кнопок, линий, карточек, плашек секций.

## Команды

- `npm run dev` — дев-сервер на `127.0.0.1:4321` (хост обязателен, порт свой).
  Сайт живёт на **http://127.0.0.1:4321/chashchina-site/**.
- `npm run build` / `npm run preview` (порт 4322).

## Деплой

GitHub Pages, репозиторий `chashchina-site`, `base: '/chashchina-site'`
(папка локально называется иначе — `oxanka`). На Vercel base переключается
на `/` автоматически.
**Все пути к ассетам и внутренним страницам — только через `asset()` из
[src/lib/asset.ts](src/lib/asset.ts)** — он нормализует слэш после BASE_URL.
Голая склейка `import.meta.env.BASE_URL + 'x'` уже ломала фотки.

## Структура

- [src/pages/index.astro](src/pages/index.astro) — вся главная: данные секций в frontmatter (массивы `steps`, `hardware`, `injTasks`, `press`…) и разметка. Своего `<style>` больше нет — стили пишем заново.
- [src/layouts/Layout.astro](src/layouts/Layout.astro) — global.css и скрипты анимаций и типографа. Шрифт подключать сюда.
- [src/components/Gallery.astro](src/components/Gallery.astro) — галерея: 10 webp, 12-колоночная рассыпанная сетка, RAF-скейл карточек от позиции скролла.
- [src/components/Header.astro](src/components/Header.astro), [Footer.astro](src/components/Footer.astro) — каркасы без оформления.
- [src/styles/global.css](src/styles/global.css) — сброс, пульт сетки/ритма (`--page-max`, `--gutter`, `--section-gap`, `--block-gap`), инварианты набора, классы анимаций. Числа в компонентах не повторять — крутить токены.
- Тексты-первоисточник: [Тексты_сайта_Чащина.md](Тексты_сайта_Чащина.md). Места с пометкой «[от Оксаны]» — заглушки.

## Фоновые процессы — только по прямой просьбе

Без явного разрешения в этом чате не запускать ничего, что само просыпается
и тратит токены:

- никаких плановых проверок и напоминалок (`send_later`, `create_trigger`,
  `ScheduleWakeup`, `CronCreate`) — в том числе «перевзвести через час»;
- не подписываться на события PR (`subscribe_pr_activity`) и не «следить»
  за пулл-реквестами — CI и комментарии смотрим руками, когда попросят;
- не плодить сабагентов, воркфлоу и параллельные сессии ради простых задач;
- фоновые команды в Bash (`run_in_background`) — только когда без них никак
  (дев-сервер), и сразу гасить.

Сделал PR — сказал ссылку и на этом всё. Эти же тулзы перечислены в
`permissions.deny` в [.claude/settings.json](.claude/settings.json).
