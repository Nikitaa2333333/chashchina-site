# Сайт Оксаны Чащиной — врач-косметолог, превентивная медицина

Персональный сайт-лендинг на Astro. Референс дизайна —
[farmminerals.com/products/croptab](https://www.farmminerals.com/products/croptab)
(швейцарская типографика, full-bleed, тонкие линии, оливковая палитра),
анимация галереи — по мотивам prmpt (скейл карточек от позиции скролла).
Подробности: [DESIGN.md](DESIGN.md) (цвета, типографика, приёмы) и
[SPACING.md](SPACING.md) (пульт отступов).

## Команды

- `npm run dev` — дев-сервер на `127.0.0.1:4321` (хост обязателен, порт свой).
  Сайт живёт на **http://127.0.0.1:4321/dr.chashchina/** — задан `base: '/dr.chashchina'`.
- `npm run build` / `npm run preview` (порт 4322).

## Принципы дизайна (кратко; полностью — DESIGN.md)

- **Два цветовых трека**: зелёный (#5c6b3c/#404f1d) = внутреннее/медицина + весь служебный UI; розовый (#c08379/#f7edea) = внешнее/эстетика (аппаратные, инъекции, зоны, уход). Плашка и бирки секции меняются вместе; розовый с тёмно-зелёным не смешивать. `<mark>` всегда шалфейный.
- Onest, тонкие крупные заголовки (300–330), отрицательный трекинг; **капс запрещён**, жирный/курсив в наборе запрещены (в CSS предохранители).
- Скругления 0. Линии 1px и только структурные (спек-листы, таблицы, шапка/футер).
- Мера строки токенами `--measure-*` в `ch` на самом текстовом элементе.
- Ритм: `--section-gap` и модификаторы `.section--tight/--flush-*`; шапка секции: `.tag + h2 { 12px }`, `h2 + p { 16–26px }` — глобально.
- Анимации без библиотек: `[data-split]` (посимвольно, случайный порядок), `.reveal`/`.reveal-group` (fade/rise каскадом), галерея на RAF с lerp. Всё гаснет при `prefers-reduced-motion`.
- Hover — только opacity (.7). Яркие цвета запрещены, красный — только ошибки.
